# Security reporting

Use GitHub's private vulnerability reporting for
[rbeauchamp/acorn](https://github.com/rbeauchamp/acorn/security/advisories/new):
Security → Advisories → Report a vulnerability. Richard Beauchamp is the
responsible maintainer. Do not disclose vulnerabilities, credentials or private
run data in a public issue. No response-time or remediation-time promise is made.

Include the affected revision, impact, relevant code paths, assumptions and the
smallest safe reproduction or reasoning needed to assess the report. Avoid
accessing other people's systems or data.

This is research software, not a hardened multi-user service. The viewer is
intended for loopback use and its run directory belongs to the local operator.
Do not expose it through a public proxy or serve sensitive run data to untrusted
users. A local executable command is executed with the operator's permissions.

GitHub private vulnerability reporting is enabled and verified as part of
publication, immediately after the repository becomes public. Until that
activation, this document describes the prepared route, not an already enabled
reporting facility.
